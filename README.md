# 声入星海 · 张杰粉丝音乐网站

这是一个完全本地、无需安装依赖的单页音乐网站，使用此前整理的张杰舞台图片和 9 首本地 MP3。

## 打开方式

直接双击 `index.html` 即可使用。若浏览器限制本地音频，可在本目录启动任意静态文件服务器后访问。

## 已实现

- 9 首歌曲真实播放、暂停与切换
- 上一首、下一首、自动续播
- 播放进度拖动、时间显示、音量与静音
- 歌曲切换时同步图片、文字、主题色和播放状态
- 桌面横版首屏与移动端竖版主图
- 播放时出现低透明度环境声波，暂停后自动收起
- 四张现场记忆图片组成响应式舞台拼贴
- 自适应歌单、固定播放器、移动导航
- 键盘空格播放，左右方向键快进或后退 5 秒
- 音频错误提示与减少动态效果支持

## 文件结构

- `index.html`：页面结构
- `styles.css`：完整视觉与响应式样式
- `app.js`：歌单数据和播放器交互
- `assets/images`：网站图片
- `assets/images/optimized`：页面实际使用的 WebP 多尺寸图片
- `assets/audio`：9 首本地音乐

本项目为个人非商业粉丝作品。
